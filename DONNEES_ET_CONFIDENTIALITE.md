# Données et confidentialité

Les données enregistrées sont limitées aux comptes, profils familiaux et rendez-vous saisis volontairement.

- GitHub Pages héberge le code de l’interface, pas les rendez-vous.
- Supabase héberge les comptes et la base PostgreSQL.
- Le navigateur conserve une copie locale nécessaire au mode hors ligne.
- Aucun outil publicitaire, analytique ou traceur tiers n’est intégré.
- Le SDK Supabase est chargé depuis jsDelivr puis mis en cache pour le fonctionnement hors ligne.

L’administrateur peut exporter les données de la famille au format JSON depuis l’application.
