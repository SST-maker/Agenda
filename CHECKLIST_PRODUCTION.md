# Checklist production

- [ ] `supabase/schema.sql` exécuté sans erreur.
- [ ] URL Supabase et Publishable key ajoutées aux variables GitHub Actions.
- [ ] Aucune clé `service_role` présente dans le dépôt.
- [ ] GitHub Pages configuré sur **GitHub Actions**.
- [ ] Site URL et Redirect URLs configurées dans Supabase Auth.
- [ ] Compte Nacer créé et e-mail confirmé.
- [ ] Invitation Romane testée.
- [ ] Création, modification et suppression synchronisées sur deux appareils.
- [ ] Test hors ligne puis resynchronisation effectué.
- [ ] Installation PWA testée sur les deux téléphones.
- [ ] Export JSON téléchargé et conservé en lieu sûr.
